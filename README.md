# 2048 Web Game

经典 2048 数字合成网页小游戏。

## 开始游戏

直接用浏览器打开 `index.html` 即可运行。

## 操作方式

| 操作 | 按键 |
|------|------|
| 左移 | `←` / `A` |
| 右移 | `→` / `D` |
| 上移 | `↑` / `W` |
| 下移 | `↓` / `S` |
| 新游戏 | `R` |

移动端：支持滑动屏幕操作。

## 项目结构

```
2048-game/
```

## 核心规则

- 4×4 棋盘，初始随机生成两个方块（90% 概率为 2，10% 概率为 4）
- 每次有效移动后在空格随机生成一个方块
- 相同数字碰撞合并，每次合并每个方块只能合并一次
- 无空格且无可合并相邻方块时游戏结束
- 合成 2048 即获胜，可选择继续挑战更高数字
